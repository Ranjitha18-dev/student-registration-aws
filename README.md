# Student Registration System (AWS Serverless)

## Project Description
This project is a serverless web application for registering students using AWS services.

## AWS Services Used
- AWS Lambda
- API Gateway
- DynamoDB
- CloudWatch

## Features
- Add student details
- View student list
- Serverless architecture

## Frontend
HTML + JavaScript (Fetch API)

## API Endpoint
https://your-api-id.execute-api.ap-south-1.amazonaws.com/prod/students

## How it works
Frontend sends request → API Gateway → Lambda → DynamoDB
